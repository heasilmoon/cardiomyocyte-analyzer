Cardiomyocyte Analyzer

이 페이지는 안내용입니다. 분석 앱은 Python 서버가 영상을 계산하기 때문에 GitHub Pages(정적 호스팅)에서는 실행되지 않습니다. 아래 중 하나로 실행하세요.

  • 내 컴퓨터: 저장소를 내려받아 run_mac.command(Mac) 또는 run_windows.bat(Windows)를 두 번 클릭.
  • GitHub Codespaces: 저장소 페이지 → Code → Codespaces → Create codespace on main.
  • Hugging Face Spaces: 랩 전체가 쓰는 공용 주소. 설정 방법은 README 참고.
