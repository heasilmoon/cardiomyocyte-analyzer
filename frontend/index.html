Cardiomyocyte Analyzer

심근세포 2D/3D 영상(mp4) 분석 — 박동, 칼슘 이미징, 형태 분석

밝은 시야(bright-field) 영상에서 픽셀 변화량을 이용해 수축/이완 신호를 추출하고 박동을 검출합니다. Fiji MUSCLEMOTION 플러그인과 동일한 방식으로, 기본값은 기준(이완기) 프레임 대비 차이를 사용합니다. 박동 수가 실제와 다르면(너무 많음=노이즈 오검출, 너무 적음=약한 박동 누락) "피크 민감도"를 0.05~0.2 사이에서 조정하며 다시 분석해보세요 — 이 값은 영상마다 조금씩 다를 수 있습니다.

형광 강도(intensity) 변화를 ΔF/F0로 정규화하고 칼슘 트랜지언트를 검출합니다.

2D: 대표 이미지(최대 강도 투영)에서 세포를 분할해 개수/면적 등을 계산합니다. 3D: 영상의 각 프레임을 z-slice로 간주해 부피 기반 형태를 계산합니다. "구조 텐서 정렬도"를 켜면 세그멘테이션 없이 픽셀(voxel) 단위로 국소 방향을 계산합니다 (Cardiotensor/OrientationJ 방식) — sarcomere 줄무늬나 섬유 조직처럼 개별 세포로 나누기 애매한 구조의 정렬도를 볼 때 유용합니다.

같은 분석(박동/칼슘/형태)을 여러 영상에 대해 돌린 뒤, 두 그룹(예: 대조군 vs 처리군) 간 각 지표를 Mann-Whitney U 검정으로 비교합니다. 각 그룹에 영상을 여러 개 선택해서 올려주세요.

1단계 — 배치 분석

같은 분석 종류의 영상을 여러 개 한 번에 올려서, 영상별 결과가 담긴 CSV를 받습니다. 이 CSV의 값과 Fiji로 따로 뽑은 값을 나란히 놓으면 2단계 일치도 분석에 쓸 수 있어요.

2단계 — 일치도(Agreement) 분석

이 도구의 값과 Fiji(또는 다른 기준 방법) 값이 짝지어진 CSV를 올리면, 상관계수·ICC(2,1)· Bland-Altman bias 및 95% 일치 한계를 계산하고 논문용 그림을 만들어줍니다. CSV에는 각 영상당 한 행, 두 개의 숫자 열(이 도구 값, Fiji 값)이 있어야 합니다.
