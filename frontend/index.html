Cardiomyocyte Analyzer

심근세포 2D/3D 영상(mp4) 분석 — 박동, 칼슘 이미징, 형태 분석

밝은 시야(bright-field) 영상에서 픽셀 변화량을 이용해 수축/이완 신호를 추출하고 박동을 검출합니다. Fiji MUSCLEMOTION 플러그인과 동일한 방식으로, 기본값은 기준(이완기) 프레임 대비 차이를 사용합니다. 박동 수가 실제와 다르면(너무 많음=노이즈 오검출, 너무 적음=약한 박동 누락) "피크 민감도"를 0.05~0.2 사이에서 조정하며 다시 분석해보세요 — 이 값은 영상마다 조금씩 다를 수 있습니다. "piv" 모드는 PIV-MyoMonitor(soahleelab)와 같은 계열의 알고리즘(FFT 기반 windowed cross-correlation)으로 프레임 간 변위 벡터장을 계산합니다 — 스칼라 신호가 아니라 실제 방향+크기 정보를 가진 모션 필드를 얻을 수 있지만 계산이 더 오래 걸립니다.

영상을 선택하면 첫 프레임이 아래 나타납니다. 마우스로 드래그해서 분석할 영역만 지정할 수 있어요(예: 배경/어두운 영역 제외). 지정하지 않으면 전체 화면을 씁니다.

전체 화면 사용 중

형광 강도(intensity) 변화를 ΔF/F0로 정규화하고 칼슘 트랜지언트를 검출합니다.

영상을 선택하면 첫 프레임이 아래 나타납니다. 마우스로 드래그해서 분석할 영역만 지정할 수 있어요. 지정하지 않으면 전체 화면을 씁니다.

전체 화면 사용 중

2D: 대표 이미지(최대 강도 투영)에서 세포를 분할해 개수/면적 등을 계산합니다. 3D: 영상의 각 프레임을 z-slice로 간주해 부피 기반 형태를 계산합니다. "구조 텐서 정렬도"를 켜면 세그멘테이션 없이 픽셀(voxel) 단위로 국소 방향을 계산합니다 (Cardiotensor/OrientationJ 방식) — sarcomere 줄무늬나 섬유 조직처럼 개별 세포로 나누기 애매한 구조의 정렬도를 볼 때 유용합니다.

같은 분석(박동/칼슘/형태)을 여러 영상에 대해 돌린 뒤, 두 그룹(예: 대조군 vs 처리군) 간 각 지표를 Mann-Whitney U 검정으로 비교합니다. 각 그룹에 영상을 여러 개 선택해서 올려주세요. 한 샘플(배치/웰)에서 여러 영상을 찍었다면, 아래 "배치/샘플 라벨"에 영상 업로드 순서대로 한 줄씩(또는 쉼표로) 라벨을 적어주세요 — 같은 샘플에서 나온 여러 측정을 독립적인 것처럼 취급하면 통계적으로 거짓양성이 늘어나는데(pseudoreplication), 이 경우 선형 혼합효과 모델(LMM)로 샘플 ID를 랜덤효과로 넣어 이 문제를 보정한 p-value도 같이 계산해드립니다. 비워두면 기존처럼 Mann-Whitney U만 계산합니다.

1단계 — 배치 분석

같은 분석 종류의 영상을 여러 개 한 번에 올려서, 영상별 결과가 담긴 CSV를 받습니다. 이 CSV의 값과 Fiji로 따로 뽑은 값을 나란히 놓으면 2단계 일치도 분석에 쓸 수 있어요.

2단계 — 일치도(Agreement) 분석

이 도구의 값과 Fiji(또는 다른 기준 방법) 값이 짝지어진 CSV를 올리면, 상관계수·ICC(2,1)· Bland-Altman bias 및 95% 일치 한계를 계산하고 논문용 그림을 만들어줍니다. CSV에는 각 영상당 한 행, 두 개의 숫자 열(이 도구 값, Fiji 값)이 있어야 합니다.

멀티채널 형광 이미지에서 두 채널이 얼마나 겹치는지(colocalization) 분석합니다. Pearson 상관계수, Manders M1/M2(각 채널 신호 중 상대 채널과 겹치는 비율, Otsu 임계값 기준), Manders overlap coefficient를 계산하고, RGB 병합 이미지 + 픽셀 강도 산점도를 만듭니다. 각 채널을 mp4나 이미지로 따로 올려주세요 (두 채널은 크기가 같아야 합니다).
